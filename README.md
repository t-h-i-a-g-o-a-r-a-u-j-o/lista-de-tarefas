# 📝 Lista de Tarefas

Aplicação web para gerenciamento de tarefas desenvolvida com **HTML5, CSS3 e JavaScript puro**, com persistência de dados utilizando o **LocalStorage** do navegador.

O projeto foi desenvolvido com foco na prática de manipulação do DOM, eventos, armazenamento local e organização da lógica em JavaScript.

## 🚀 Demonstração

👉 [Acessar aplicação online](https://t-h-i-a-g-o-a-r-a-u-j-o.github.io/lista-de-tarefas/)

## ⚙️ Funcionalidades

- ➕ Adicionar novas tarefas
- ✏️ Editar tarefas existentes
- ✅ Marcar e desmarcar tarefas como concluídas
- 🗑️ Excluir tarefas
- 🧹 Limpar tarefas concluídas
- 🔎 Filtrar tarefas por Todas, Pendentes e Concluídas
- 📊 Exibir quantidade de tarefas cadastradas e pendentes
- 💾 Salvar automaticamente as tarefas no navegador
- 📱 Interface responsiva
- ⌨️ Adicionar tarefas utilizando a tecla Enter

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- DOM API
- LocalStorage
- JSON

## 💡 Conceitos aplicados

- Manipulação dinâmica do DOM
- Event Listeners
- Funções e organização da lógica da aplicação
- Arrays e métodos `map()`, `filter()`, `find()` e `some()`
- Objetos JavaScript
- Persistência de dados com `localStorage`
- Conversão de dados com `JSON.stringify()` e `JSON.parse()`
- Identificação individual das tarefas
- Tratamento dos dados armazenados
- Responsividade com Media Queries
- Atributos ARIA para acessibilidade

## 📂 Estrutura do projeto

**index.html** — estrutura da aplicação  
**style.css** — estilização e responsividade  
**script.js** — lógica, eventos e persistência dos dados  
**README.md** — documentação do projeto
